# Lecture Notes: Module 5 — Memory Management & Virtual Memory

## 1. Physical vs. Virtual Memory
- **Logical (Virtual) Address Space**: Address generated by the CPU during instruction execution.
- **Physical Address Space**: Actual physical memory location in RAM loaded into the memory bus.
- **Memory Management Unit (MMU)**: Hardware device that maps virtual addresses to physical addresses at runtime.
- **Fragmentation**:
  - *Internal Fragmentation*: Unused space inside an allocated memory partition (occurs in fixed partitioning and paging).
  - *External Fragmentation*: Total free memory space is enough to satisfy a request, but it is not contiguous (eliminated by paging).

## 2. Paging and Translation Lookaside Buffer (TLB)
- **Paging**: Physical memory is broken into fixed-sized blocks called **frames** (typically 4 KB). Logical memory is broken into blocks of the same size called **pages**.
- Logical address generated by CPU has two parts: Page number (\(p\)) and Page offset (\(d\)).
- The **Page Table** maps page number \(p\) to frame number \(f\).
- **TLB (Translation Lookaside Buffer)**: High-speed associative hardware cache.
  - When CPU references a virtual page number \(p\), it searches the TLB first.
  - **TLB Hit**: Frame number is obtained in 1 clock cycle without accessing main memory.
  - **TLB Miss**: CPU accesses the page table in main memory, retrieves the frame, and updates the TLB.
  - **Effective Memory Access Time (EMAT)**:
    \[ EMAT = (\text{Hit Ratio} \times (t_{\text{TLB}} + t_{\text{RAM}})) + ((1 - \text{Hit Ratio}) \times (t_{\text{TLB}} + 2 \times t_{\text{RAM}})) \]

## 3. Virtual Memory & Demand Paging
- Virtual memory allows the execution of processes that are not completely in physical memory, separating user logical memory from physical memory.
- **Demand Paging**: Pages are loaded into RAM only when they are demanded during execution.
- **Page Fault**: Occurs when an instruction references a page that is marked invalid or not present in physical memory.
  - Hardware traps to the operating system kernel.
  - OS locates the page on backing store (disk/swap space).
  - OS brings page into a free physical frame (or invokes page replacement).
  - OS updates page table (valid bit set to 1) and restarts the instruction.

## 4. Page Replacement Algorithms
- **FIFO (First-In, First-Out)**: Replaces the oldest page loaded into memory. Suffers from **Belady's Anomaly** (page fault rate may increase as the number of allocated physical frames increases).
- **Optimal Page Replacement (OPT / MIN)**: Replaces the page that will not be used for the longest period of time in the future. Provably minimum page fault rate; used as an unattainable theoretical benchmark.
- **LRU (Least Recently Used)**: Replaces the page that has not been referenced for the longest period in past execution. Does not suffer from Belady's anomaly. Implemented using counters or hardware stack.
- **Thrashing**: If a process does not have enough frames, page faults occur constantly. The CPU spends more time swapping pages into and out of disk than executing instructions, causing CPU utilization to plummet to near zero.
